= Irurueta Android GL Cube

NOTE: This documentation was generated with the assistance of AI. Please report any inaccuracies.

*irurueta-android-gl-cube* is an Android library that provides `CubeTextureView`, a view that draws a 3D cube with
OpenGL ES 2.0 on a transparent background. It is a compact, working example of how to use
https://github.com/albertoirurueta/irurueta-android-glutils[irurueta-android-glutils] to render a 3D scene from a
pinhole camera.

image::video.gif[Demo of CubeTextureView: a rotating cube drawn over a text view, with an animated camera skewness,width=304]

Because `CubeTextureView` extends `GLTextureView` (a `TextureView` based OpenGL view from irurueta-android-glutils)
instead of `GLSurfaceView`, it behaves like any other view in the hierarchy: it can be placed on top of or below
other views, it can be translucent, and it can be moved, scaled, rotated or animated with regular view properties.
In the demo above, the text is a plain `TextView` placed behind the cube.

== Features

* 3D cube with a different color on each vertex, drawn with OpenGL ES 2.0 shaders.
* Transparent background by default (`clearColor` is `Color.TRANSPARENT`), so the cube can be composed with other
  views.
* Configurable cube size, position and rotation, using `Point3D` and `Rotation3D` from
  https://github.com/albertoirurueta/irurueta-geometry[irurueta-geometry].
* Scene camera defined as a `PinholeCamera` (intrinsic parameters, center and rotation), with near and far clipping
  planes.
* Conversion from an OpenGL projection matrix (for instance, the one provided by ARCore) to pinhole camera intrinsic
  parameters through `OpenGlToCameraHelper`.
* Optional camera expressed in Android view coordinates once the display orientation is known.
* Frames are rendered only when something changes (`RENDER_MODE_WHEN_DIRTY`): every property setter requests a new
  frame, so the view does not consume GPU when idle.

== Core concepts

[mermaid]
....
flowchart LR
    A["Activity / Fragment"] -->|"properties: cube, camera, colors"| V["CubeTextureView (GLTextureView)"]
    V -->|"delegates and requests render"| R["CubeRenderer"]
    R -->|"PinholeCamera to OpenGL matrices (irurueta-android-glutils)"| G["OpenGL ES 2.0"]
    R -.->|"OnSurfaceChangedListener"| A
....

* `CubeTextureView` is the public entry point. Its properties forward to an internal `CubeRenderer` and request a new
  frame.
* The OpenGL surface is created asynchronously. Camera related properties can only be set once the surface exists,
  which is notified through `CubeTextureView.OnSurfaceChangedListener`. See xref:usage.adoc#surface[Waiting for the
  surface].
* The scene is defined in world coordinates, where the y axis points upwards. By default the cube center is placed
  at `(0, 0, 2)`.

== Public API at a glance

[cols="1,3",options="header"]
|===
|Type
|Purpose

|`CubeTextureView`
|The view. Exposes cube, camera and color properties, and forwards them to the renderer.

|`CubeTextureView.OnSurfaceChangedListener`
|Notified when the OpenGL surface is created or resized. Use it to initialize camera related properties.

|`CubeRenderer`
|`GLTextureView.Renderer` that draws the cube. Used internally by the view; it exposes the default values
(`DEFAULT_CUBE_SIZE`, `DEFAULT_CUBE_DISTANCE`, `DEFAULT_NEAR_PLANE`, `DEFAULT_FAR_PLANE`, `DEFAULT_CLEAR_COLOR`).
|===
