== Waiting for the surface

The OpenGL surface is created asynchronously after the view is attached and laid out. Until then, the view does not
know its size in pixels, so camera related properties (`camera`, `cameraIntrinsicParameters`, `cameraCenter`,
`cameraRotation`, `nearPlane`, `farPlane`, `setNearFarPlanes`, `setValues`, `orientation` and the `viewCamera*`
properties) throw `IllegalStateException` if they are set too early.

Set `onSurfaceChangedListener` and configure the camera there. The listener is called every time the surface is
created or resized, for instance after a configuration change:

[source,kotlin]
----
include::example$surfaceChanged.kt[]
----

Cube and color properties (`cubeSize`, `cubePosition`, `cubeRotation`, `clearColor` and `diffuseColor`) can be set at
any time.

[NOTE]
====
`onSurfaceChanged` is called from the OpenGL rendering thread. Setting the view properties from there is safe, but
post to the main thread (for instance with `view.post { ... }`) if you also need to update other views.
====

== Rendering model

The view renders only on demand (`RENDER_MODE_WHEN_DIRTY`). Every property setter of `CubeTextureView` requests a new
frame, so there is no need to call `requestRender()` yourself, and an idle cube does not use the GPU. To animate the
cube, update its properties from an animator, as described in xref:animation.adoc[Animation].
