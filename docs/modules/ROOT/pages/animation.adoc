== Animating the camera

Camera parameters can be animated in the same way, once the surface exists. The sample app oscillates the camera
skewness, which produces the shearing effect shown in the demo:

[source,kotlin]
----
val skewAnimator = ValueAnimator.ofFloat(-1000f, 1000f).apply {
    duration = 1000L
    repeatMode = ValueAnimator.REVERSE
    repeatCount = ValueAnimator.INFINITE
    interpolator = AccelerateDecelerateInterpolator()
    addUpdateListener { animator ->
        val camera = camera ?: return@addUpdateListener // created in onSurfaceChanged
        val intrinsics = camera.intrinsicParameters
        intrinsics.skewness = (animator.animatedValue as Float).toDouble()
        camera.intrinsicParameters = intrinsics
        cubeView.camera = camera
    }
}

// Play both animations together
AnimatorSet().apply {
    playTogether(rotationAnimator, skewAnimator)
    start()
}
----

Remember to pause the animators in `onPause` along with the view, and to resume them in `onResume`.
